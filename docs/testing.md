# خطة الاختبار

## وحدات (Unit)

```bash
cd backend
python manage.py test apps.accounts apps.documents apps.sharing apps.audit
```

- اختبارات التشفير: round-trip + كشف العبث.
- اختبارات المصادقة: قفل الحساب، كلمات المرور.
- اختبارات المشاركة: انتهاء الصلاحية، صلاحيات.
- اختبارات سجل التدقيق: الإنشاء والترتيب.

## التكامل (Integration)

- رفع وثيقة ثم تحميلها وفك تشفيرها.
- دورة مصادقة كاملة (register → verify → login → refresh → logout).
- مشاركة وثيقة ووصول عام برمز.

## يدوي (Manual)

- واجهة المستخدم (RTL/عربي).
- مصادقة ورفع ومشاركة وعرض سجل التدقيق.
- تعدد المستخدمين وعزل بياناتهم.

## الأمان (Security)

- محاولات تسجيل دخول فاشلة × 6 → قفل الحساب.
- الوصول لموارد بدون رمز → 401.
- عبث بملف مشفر → رفض فك التشفير.
