# دليل المستخدم

نظام إدارة وثائق آمن ومشفر.

## البدء

1. أنشئ حساباً جديداً من صفحة التسجيل.
2. فعّل بريدك الإلكتروني عبر الرابط المرسل.
3. سجّل الدخول.

## رفع وثيقة

- من صفحة "الوثائق"، اضغط **رفع وثيقة**.
- اختر الملف وأدخل العنوان والتصنيف.
- تُشفَّر الوثيقة فوراً باستخدام AES-256-GCM قبل الحفظ.

## مشاركة وثيقة

- من صفحة "المشاركة"، اضغط **مشاركة وثيقة**.
- أدخل بريد المستلم وحدد الصلاحية (عرض/تحرير/تعليق/كاملة).
- يصل المستلم بريداً برابط آمن.

## الأمان

- كلمة مرور قوية (أحرف كبيرة وصغيرة وأرقام ورمز خاص).
- قفل الحساب بعد 5 محاولات خاطئة.
- توثيق JWT مع تحديث تلقائي.

## سجل التدقيق

- يعرض كل العمليات الحساسة (عرض/تحميل/مشاركة/حذف).
- متاح لكل مستخدم لسجلاته وللمشرف لكل السجلات.
